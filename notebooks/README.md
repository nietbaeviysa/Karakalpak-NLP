# Karakalpak NLP — Каракалпак тили корпусы

First open-source NLP project for the Karakalpak language — 
a low-resource Turkic language spoken by 700,000 people.

## About
This project analyzes Karakalpak dastan (epic poetry) texts 
using Python and NLP tools to create the first frequency 
vocabulary of the Karakalpak language.

**Author:** Iysa Nietbaev — English Philologist & NLP researcher  
**Institution:** Karakalpakh State University, Nukus, Uzbekistan

## Dataset
Three classic Karakalpak dastans:
- Қырқ қыз (Qiriq Qiz) — Forty Girls
- Қоблан (Qoblan)
- Ер Зияр Қурбанбек (Er Ziyar Qurbanbek)

## Results
- Total unique words: **17,293**
- Total corpus size: ~650,000 characters
- Frequency vocabulary saved as CSV

## Why this matters
Karakalpak has almost no digital NLP resources.
This project is the first step toward:
- Digital preservation of oral epic tradition
- Educational materials in the native language
- NLP tools for low-resource Turkic languages
